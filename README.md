# SecretBurrow

**Client-side firmware & source-code secret scanner.**

🚀 **Quick Demo:** https://giriaryan694-a11y.github.io/SecretBurrow/

SecretBurrow analyzes repositories and firmware locally in the browser to uncover exposed secrets, credentials, hashes, encodings, crypto material, and suspicious high-entropy data.

### Features

* 🔍 Secret & credential detection
* 🧩 Firmware/container/filesystem analysis
* 🔓 Encoding & decoding analysis
* #️⃣ Hash identification
* 🔐 Crypto/key material detection
* 📦 Archive & nested-content scanning
* 📁 Recursive filesystem analysis
* 🖥️ Verbose live status terminal
* 📊 Scan progress tracking
* 🔎 Findings search/filter
* 📤 Export findings as CSV, SQL, Markdown, TXT, JSON & PDF
* 🛡️ Client-side processing
